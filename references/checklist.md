# 诊断执行清单

打印或复制进表格，从上往下走。每一步都有「做完的标志」，没达到就停在这步。

## 第 0 步：判断素材

- [ ] 能逐条列出最近 20 条作品的时长 + 点赞 + 评论 + 收藏 + 转发 → **走 A**
- [ ] 只有主页链接，只能看到前几条 → **走 B**
- [ ] 只有主页截图 → **走 B**
- [ ] 有创作者后台截图 → **走 A（受限）**，私有数据不外传

> 做完的标志：能明确说出手上有几条可逐条记录的样本。

## 路径 A：有数据

### A1 取样本

- [ ] 取最近 20 条，按时间顺序，不挑选
- [ ] 不混入更早的作品
- [ ] 记录五项：时长、点赞、评论、收藏、转发

> 做完的标志：表格里有 20 行完整数据，空值标「无」不标 0。

### A2 算中位数

- [ ] 四项互动的中位数（不是平均数）
- [ ] 时长的中位数

> 做完的标志：能说出「点赞中位数 X，收藏中位数 Y」。如果说的是平均数，重算。

### A3 分档

| 时长档 | 条数 | 点赞中位数 | 收藏中位数 |
| --- | --- | --- | --- |
| 1 分钟以内 | | | |
| 1–3 分钟 | | | |
| 3–5 分钟 | | | |
| 5–10 分钟 | | | |
| 10 分钟以上 | | | |

- [ ] 每档记条数
- [ ] 不足 3 条的档不参与判断，只记录

> 做完的标志：五档都有条数，能一眼看出哪档最多。

### A4 找缺口

- [ ] 条数最多的那一档是：___
- [ ] 这一档的点赞中位数是否全档最低：是 / 否
- [ ] 这一档的收藏中位数是否也最低：是 / 否

> 做完的标志：如果两个「是」，缺口成立，可以进 A5。如果只有一个「是」，说明证据不足，回到 A1 检查数据。

### A5 定动作

- [ ] 只选一个要改的变量：___
- [ ] 写清楚两周后看哪个指标
- [ ] 写清楚什么情况算「没改善」

> 做完的标志：动作栏只有一个条目。填了两个以上，四周后无法归因。

## 路径 B：只有截图

- [ ] 定位：简介 / 认证 / 封面风格是否统一 → 一致 / 部分一致 / 分散
- [ ] 选题：最近几条是否集中在一个领域 → 收敛 / 持平 / 发散
- [ ] 标题：句式、字数、有没有明确承诺 → 承诺明确 / 模糊 / 无承诺
- [ ] 互动：点赞评论的量级范围（不给百分比）
- [ ] 节奏：发布日期是否规律 → 稳定 / 波动 / 断更

> 做完的标志：五个维度都有三档结论，**且没有出现任何一个百分比**。出现了就删掉。

## 收尾检查

交出去之前逐条过：

- [ ] 有没有给出总分？有就删掉，改成分档
- [ ] 有没有出现「大概多少播放」「预计涨粉」？有就删掉
- [ ] 有没有在路径 B 里给了百分比？有就删掉
- [ ] 「优先改一件事」是不是只有一个？
- [ ] 有没有说明样本是最近 20 条、时间窗是什么？
- [ ] 有没有写清楚哪些数据拿不到？没有就补一段
- [ ] 有没有把「同向变化」写成「因为所以」？有就改成「同时出现」

## 一句话自检

如果这份诊断换一个人重新跑一遍，结论会不会落到同一档？

不会 → 说明还有步骤没定死，回到对应步骤补规则。
会 → 可以交。
