# 六维度判定基准与字段可得性

查表用。想知道为什么这么定，看 [`../SKILL.md`](../SKILL.md)。

## 一、粉丝分档

跨档比较没有意义。同一维度只跟同档账号的中位数比。

| 档位 | 粉丝区间 |
| --- | --- |
| 起步 | 1 万以下 |
| 成长期 | 1–10 万 |
| 成熟期 | 10–50 万 |
| 头部 | 50 万以上 |

## 二、六个维度

每个维度只有三档结果，不给分数。

### 1. 定位清晰度

- **看什么**：简介、认证、最近 10 条选题是否指向同一群人
- **跟谁比**：同粉丝档、同赛道账号
- **三档**：一致 / 部分一致 / 分散
- **判定要点**：
  - 一致 = 简介说的人群和最近 10 条内容面向的人群是同一个
  - 部分一致 = 主体一致，但有不属于该人群的内容（一般 ≤3 条）
  - 分散 = 最近 10 条覆盖超过 3 个不相关人群
- **常见误判**：把「什么都做」当成覆盖面广。覆盖面是给同一个人的不同需求，不是给不同的人。

### 2. 内容垂直度

- **看什么**：最近 20 条跨了几个主题
- **跟谁比**：你自己上一批作品（不是别人）
- **三档**：收敛 / 持平 / 发散
- **判定要点**：
  - 收敛 = 主题数比上一批减少，或同一主题占比上升
  - 持平 = 主题分布与上一批接近
  - 发散 = 主题数增加，且没有单一主题超过 40%
- **常见误判**：把系列内容当成不同主题。同一个选题的连续三条算一个主题。

### 3. 选题结构

- **看什么**：每条讲的是观点、教程、故事还是清单
- **跟谁比**：同档账号的选题分布
- **三档**：有主结构 / 混杂 / 无结构
- **判定要点**：
  - 有主结构 = 60% 以上属于同一类，且其余是它的变体
  - 混杂 = 有两类各占 30% 以上
  - 无结构 = 看不出主导类型
- **常见误判**：把标题当选题。标题是表达方式，选题是「对谁讲什么问题」。

### 4. 标题与开头钩子

- **看什么**：前 3 秒说了什么，标题承诺了什么
- **跟谁比**：同档账号里互动最高的 5 条
- **三档**：承诺明确 / 模糊 / 无承诺
- **判定要点**：
  - 承诺明确 = 前 3 秒说清了「看完能获得什么」，且这个承诺在正文里兑现
  - 模糊 = 有方向但没具体交付物
  - 无承诺 = 只有情绪或悬念，没给信息
- **常见误判**：把悬念当钩子。「你一定想不到」是空钩子，不是承诺。

### 5. 更新节奏与产能

- **看什么**：最近 20 条的时间间隔
- **跟谁比**：你自己历史节奏（不是别人的更新频率）
- **三档**：稳定 / 波动 / 断更
- **判定要点**：
  - 稳定 = 间隔的标准差在均值 50% 以内
  - 波动 = 超过 50% 但最近一条在 14 天内
  - 断更 = 最近一条超过 14 天
- **常见误判**：把日更当唯一正确答案。日更但每条都弱，不如周更但每条能立住。

### 6. 互动效率

- **看什么**：点赞、评论、收藏三项的中位数
- **跟谁比**：同粉丝档账号的中位数
- **三档**：高于 / 落在区间 / 低于
- **判定要点**：
  - 高于 = 三项里有两项高于同档中位数
  - 落在区间 = 有一项高于、一项低于
  - 低于 = 三项都低于
- **常见误判**：用单条爆款代表整体。先算中位数。

**收藏比点赞更能反映内容是否被存下来。** 收藏率高的内容是被当作工具反复用的，点赞高的可能只是被看完了。

## 三、字段可得性对照

判定时必须按平台实际能拿到的字段退。拿不到的写「拿不到」，不估算。

| 字段 | 小红书公开主页 | 抖音公开主页 | B站公开主页 |
| --- | --- | --- | --- |
| 粉丝数 | 可见 | 可见 | 可见 |
| 总获赞 | 可见 | 可见 | 可见 |
| 单条点赞 | 可见 | 可见 | 可见 |
| 单条评论 | 可见 | 可见 | 可见 |
| 单条收藏 | 可见 | 可见 | 可见 |
| 单条转发/分享 | ❌ 不可见 | 可见 | 可见 |
| 单条播放量 | ❌ 不可见 | ❌ 不可见 | **可见** |
| 完播率 | ❌ 不可见 | ❌ 不可见 | ❌ 不可见 |
| 涨粉数 | ❌ 不可见 | ❌ 不可见 | ❌ 不可见 |
| 成交/带货数据 | ❌ 不可见 | ❌ 不可见 | ❌ 不可见 |

由此得出三条硬边界：

1. **任何平台都算不出完播率**——三个平台公开主页都没有这个字段
2. **小红书算不出转发率**，只有抖音和 B站可以
3. **只有 B站能算播放量相关的比率**（点赞/播放），小红书和抖音不能

## 四、为什么不做总分

权重无法普适。三个具体理由：

1. **赛道差异**：亲子号和知识号对「更新节奏」的敏感度完全不同。亲子号断更两周可能没影响，知识号断更两周权重掉得明显
2. **阶段差异**：1 万粉以下，定位清晰度的影响远大于互动效率；50 万以上反过来
3. **数据缺口差异**：路径 B 只有定性判断，本来就没有可加权的数值

替代做法是**排序而不是求和**：先算出每个维度「离同档中位数差多少」，再筛掉你改不动的，剩下差额最大的那一个就是优先项。

## 五、样本量的硬规定

| 项目 | 规定 | 原因 |
| --- | --- | --- |
| 取多少条 | 最近 20 条 | 少于 20 条，中位数不稳定 |
| 是否混历史 | 不混 | 混了就无法反映当前水平 |
| 是否挑选 | 不挑，按时间顺序取 | 挑了就等于先有结论再找证据 |
| 分档后每档最少几条 | 3 条 | 不足 3 条的档不参与判断，只记录 |
| 改动作后多久复看 | 两周 | 短于两周，平台分发还没跑完 |
